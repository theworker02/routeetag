# routeetag

Route structured JSON etag payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/routeetag/

## Install / run

```bash
git clone https://github.com/theworker02/routeetag.git
cd routeetag
node src/cli.js
node --test
```
